Place these files in your public assets directory.

Add to the HTML head (adjust paths for your site):
<link rel="icon" href="/favicon.svg" type="image/svg+xml">
<link rel="alternate icon" href="/favicon.ico">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">

SVG automatically uses white links on dark browser themes. PNG/ICO use the original teal and yellow on transparency. The Apple touch icon uses a white background.
